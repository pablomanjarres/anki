# ChatGPT connection and daily task

Create a dedicated private Secure MCP Tunnel named **Anki** in the OpenAI Platform. Connect it to the personal ChatGPT workspace, then run `python3 ops/install_tunnel.py tunnel_...` with its ID. This uses the existing Cortex tunnel client's runtime key and supervises a separate Anki MCP process. Add the tunnel as an **Anki** app in ChatGPT. A local MCP process alone is not reachable from ChatGPT.

Create a ChatGPT scheduled task for **7:00 a.m., America/Bogota** with this prompt:

> Use @Anki every morning to call `get_generation_context` for today's Bogota date. If today's run is complete, stop. Make up to five basic or cloze cards from eligible passages only. Follow the returned `cardRules`: each question must test one specific fact and make sense without its source; its answer should be one short phrase, preferably 1–6 words, never a list or two joined claims. Check that only that answer fits. Avoid broad prompts such as “What common problems does X have?”; use a single precise cloze deletion if that is clearer. Skip a passage when it has no clean recall target. For every card, use its `sourcePassageId`, quote an exact supporting sentence in `evidence`, and put the short answer in that quote. Do not use future material, unread book pages or locations, or facts absent from the passage. If no suitable material exists or the unreviewed pool is full, call `submit_generated_cards` with an empty `cards` array to record a zero-card run. Otherwise call `submit_generated_cards` once with the returned daily run key and up to five cards. Call `get_generation_run` to verify the saved result. If a tool or source read fails, call `record_generation_failure` with the daily run key and a short reason. Report the saved card count and any rejected cards.

The task must be tested from the native ChatGPT phone app with an `@Anki` tool call. A completed desktop MCP call does not establish phone access or an unattended scheduled run.
